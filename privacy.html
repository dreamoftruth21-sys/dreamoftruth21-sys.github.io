큐데스크 개인정보처리방침

시행일: 2026년 11월 7일

큐데스크는 유튜브 채널 「Re:제로부터 시작하는 신앙생활」의 운영자가 자기 컴퓨터에서만 쓰는 영상 편집 프로그램입니다. 이 문서는 큐데스크가 Google 계정과 YouTube에서 받는 정보를 어떻게 다루는지 설명합니다.

1. 받는 정보

운영자가 직접 Google 계정으로 로그인해 허락한 경우에만 아래 권한을 씁니다.

  • YouTube 동영상 업로드: 운영자 본인 채널에 영상과 썸네일을 올립니다.
  • YouTube 계정 관리: 운영자 본인 채널의 이름을 확인하고, 올린 영상의 제목·설명 같은 정보를 고칩니다.
  • YouTube Analytics 읽기: 운영자 본인 채널 영상의 시청 지속률 같은 통계를 읽습니다.

2. 저장하는 곳

  • 로그인 정보(토큰)는 운영자 컴퓨터의 Windows 자격 증명 관리자에만 저장합니다.
  • 채널 이름과 읽어 온 통계는 운영자 컴퓨터의 큐데스크 폴더에만 저장합니다.
  • 큐데스크는 별도의 서버를 운영하지 않습니다.

3. 쓰는 목적

받은 정보는 운영자 본인 채널에 영상을 올리고, 다음 영상 편집에 참고하는 데만 씁니다. 광고, 판매, 다른 사람의 정보 수집에는 쓰지 않습니다.

4. 다른 곳에 넘기는지

Google 계정과 YouTube에서 받은 정보를 제3자에게 팔거나 넘기지 않습니다.

5. Google API 서비스 사용자 데이터 정책

큐데스크가 Google API에서 받은 정보를 쓰고 다른 앱으로 옮기는 방식은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

6. 연결 끊기와 삭제

  • 큐데스크의 「설정 → 연결」에서 「연결 끊기」를 누르면 저장된 로그인 정보와 채널 정보가 지워집니다.
  • Google 계정의 서드파티 앱 권한에서도 언제든 큐데스크의 권한을 거둘 수 있습니다.
